This vignette lays out the end-to-end pipeline for stem (and soil) chamber fluxes as it is run in practice, and shows where each stemflux function plugs into the standard goFlux sequence. Chunks that require an interactive graphics device are marked and not evaluated when the vignette is built; the non-interactive alternatives are shown next to them. See “From raw trace to reported flux” for a fully evaluated single closure.

import -> auxfile -> obs.win -> window selection -> process_fluxes()
                                                     = goFlux -> best.flux -> flag_detection -> qc_screens
                                                  -> write_outputs()

Ebullition (bubbles under floating chambers or from flooded stems) is an opt-in add-on switched on with process_fluxes(ebullition = ...); see vignette("ebullition", "stemflux"). Upland soil and stem users never need it.

1. Import

For an LI-7810, subset the campaign-long .data file to the field days before importing; for LGR/UGGA folders with subdirectories and occasional corrupt files, import file by file.

library(goFlux)
library(stemflux)

# LI-7810: a 160 MB file -> only the field days
licor <- import_li7810_subset(
  "data/licor/TG10-01503-2026-05-01T000000.data",
  dates = c("2026-05-22", "2026-05-23", "2026-05-24"),
  outfile = "data/licor/subset.data",
  date.format = "ymd", timezone = "UTC",
  prec = c(3.5, 0.6, 45))                    # LI-7810 datasheet, 1 s (feeds goFlux's own MDF only)

# LGR / UGGA: recursive, one file at a time, nothing written to getwd()
lgr <- import2RData_flat("data/LGR1", instrument = "UGGA",
                         pattern = "_f\\d+\\.txt$",
                         date.format = "mdy", timezone = "UTC",
                         prec = c(0.35, 0.9, 200))

2. Auxfile

One row per closure with goFlux’s column names. start.time is instrument time; obs.length is the planned closure length. If notebook times were written on a watch that disagrees with the analyzer clock, estimate the constant offset first (a utility, not part of the default path):

aux <- data.frame(
  UniqueID   = c("T26_DBH_r1", "T26_Base_r1"),
  start.time = as.POSIXct(c("2026-05-23 10:12:10", "2026-05-23 10:50:30"), tz = "UTC"),
  obs.length = 600,
  Area  = 4254,      # cm2
  Vtot  = 7.08,      # L
  Tcham = 24.5,      # C
  Pcham = 101.3,     # kPa
  campaign = "May-2026", tissue = "live")

fc  <- find_clock_offset(licor, aux, gas = "CO2dry_ppm", search = c(-1800, 1800), auxfile = aux)
fc$offset                 # seconds to add to notebook times; inspect fc$scores before trusting it
aux <- fc$auxfile         # start.time corrected, notebook value kept in start.time_notebook

ow <- obs.win(inputfile = licor, auxfile = aux, obs.length = 600, shoulder = 120)

3. Window selection

Three routes to the same object (a manID data frame with flag, Etime, start.time_corr, end.time_corr, obs.length_corr):

# (a) interactive, every gas visible -- needs a graphics window (not RStudio's pane)
manID <- click_peak2_stacked(ow, gases = c("CO2dry_ppm", "CH4dry_ppb", "H2O_ppm"),
                             ref.secs = 600, save.plots = "plots/windows.pdf")
manID <- click_peak2_stacked(ow, gases = "auto")     # every recognised gas column present
# (b) non-interactive: sustained CO2 rise, notebook end times as a fallback/cap
ends <- data.frame(UniqueID = aux$UniqueID,
                   end.time = as.POSIXct(c("2026-05-23 10:22:30", "2026-05-23 11:02:00"), tz = "UTC"))
manID <- auto_id_rise(ow, detect.gas = "CO2dry_ppm", gases = "auto", end.times = ends,
                      trim.secs = 30, max.secs = 600, plot.dir = "plots/auto_id")
attr(manID, "log")          # review; redo any window with (a) or (c)

# (c) explicit windows from notebooks / screenshots
win <- data.frame(UniqueID = "T26_Base_r1",
                  start = "2026-05-23 10:51:00", end = "2026-05-23 11:01:30")
manID_c <- windows_from_table(ow, win)
manID <- rbind(manID[manID$UniqueID != "T26_Base_r1", ], manID_c)

4. Flux, detection limits and QC in one call

CH4 <- process_fluxes(
  manID, aux = aux, gastype = "CH4dry_ppb",
  precision = "allan", mdf = "christiansen", conf = 0.95,   # -> sigma_emp, MDF_emp, below_MDF_emp, MDF_emp_method
  extra     = NULL,                                         # or list(precision=..., mdf=..., conf=...) / "all"
  qc        = list(c0 = list(k = 1.5), co2_tracer = list(min_slope = 0), convex = TRUE,
                   min_window = list(secs = 120), ambient_start = list(sigma = 3, secs = 10),
                   leak = list(rate = 2e-5)),               # bench leak rate, s-1; omit to skip
  group = "campaign", tissue = "tissue")
CO2 <- process_fluxes(manID, aux = aux, gastype = "CO2dry_ppm", mdf = "two_sigma")
CH4
table(CH4$fluxes$det_class_emp); table(CH4$fluxes$qc_any)

The same steps by hand, if you want them one at a time:

CH4_flux <- goFlux(manID, "CH4dry_ppb")
CH4_best <- best.flux(CH4_flux)
CH4_best <- flag_detection(CH4_best, traces = manID, gastype = "CH4dry_ppb",
                           precision = "allan", mdf = "christiansen", conf = 0.95)
CH4_best <- qc_screens(CH4_best, traces = manID, gastype = "CH4dry_ppb", co2 = CO2$fluxes,
                       screens = list(c0 = TRUE, co2_tracer = TRUE, convex = TRUE))

Optionally feed the empirical precision back into goFlux so its own MDF column and flux.plot() annotations use it:

sig <- precision_by_id(manID, "CH4dry_ppb")
manID$CH4_prec <- sig$sigma[match(manID$UniqueID, sig$UniqueID)]
CH4_flux <- goFlux(manID, "CH4dry_ppb")     # goFlux reads the *_prec columns

4b. The four teaching cases (evaluated)

This is the logic of Figure 4 of the guidelines paper: four real closures that look alike in a flux table until the detection flag and the QC screens are applied. stemflux_examples() ships them with their real geometry (plus a synthetic uptake, f).

library(stemflux)
ex <- stemflux_examples(c("a", "b", "c", "d", "f"))
ex$aux[, c("example", "UniqueID", "what")]
#>   example              UniqueID
#> 1       a 2021-05-18_5086_I_7.0
#> 2       b   2020-09-23_5092_I_6
#> 3       c  2021-02-25_1641_WD_5
#> 4       d   2020-09-21_3589_U_6
#> 5       f     SYN_uptake_from_a
#>                                                                                                      what
#> 1                                                            high-signal valid closure (CO2 and CH4 rise)
#> 2                                                                      valid closure, CH4 below detection
#> 3                                                                       failed closure (flat CO2 and CH4)
#> 4                                                                       ambiguous: CH4 rise over flat CO2
#> 5 synthetic CH4 uptake (-0.08 ppb/s) with positive CO2; Gaussian noise at the measured Allan sigma of (a)
invisible(capture.output(
  res <- suppressWarnings(process_fluxes(ex$data, gastype = "CH4dry_ppb",
                          qc = list(c0 = TRUE, co2_tracer = TRUE, convex = TRUE, min_window = list(secs = 120))))))
out <- merge(ex$aux[, c("UniqueID", "example")], res$fluxes, by = "UniqueID")
out <- out[order(out$example), ]
out[, c("example", "best.flux", "sigma_emp", "MDF_emp", "det_class_emp", "qc_co2_slope", "qc_co2_tracer",
        "qc_convex", "qc_any")]
#>   example    best.flux sigma_emp   MDF_emp   det_class_emp qc_co2_slope qc_co2_tracer
#> 4       a  0.255675983   2.22532 0.0137646        emission   0.89418753         FALSE
#> 2       b -0.000180131   1.72061 0.0108030 below detection   0.72158795         FALSE
#> 3       c -0.000112764   2.87148 0.0254475 below detection   0.00022949          TRUE
#> 1       d  0.013659305   2.10148 0.0132230        emission  -0.00396495          TRUE
#> 5       f -0.055206054   2.17009 0.0134230          uptake   0.60033660         FALSE
#>   qc_convex qc_any
#> 4     FALSE  FALSE
#> 2      TRUE   TRUE
#> 3      TRUE   TRUE
#> 1      TRUE   TRUE
#> 5     FALSE  FALSE

Reading the rows: a is detected and passes; b is a good closure whose CH4 flux is below the detection limit (kept, flagged); c fails the CO2 tracer screen because the chamber never sealed, so its CH4 number is meaningless whatever its size; d has a clear CH4 rise but no CO2 rise, which the tracer screen flags for a look (a leak-free chamber on live tissue should accumulate CO2); f is an uptake. No row was removed.

5. Where the outputs go

write_outputs(CH4, "results/CH4")
#> results/CH4/fluxes.csv        one row per UniqueID
#> results/CH4/settings.json     every option used (methods section)
#> results/CH4/flux_plots.pdf    one page per closure (goFlux::flux.plot via flux_pdf)
#> results/CH4/ebullition_events.csv   only when the ebullition add-on ran

process_fluxes() returns a list: fluxes, events (NULL unless the ebullition add-on ran), traces (the concentration data actually fitted), gastype, settings.

goFlux columns are never modified; stemflux adds columns; nothing is removed. fluxes starts as the exact best.flux() table (same names, same values) and stemflux appends columns with distinguishable names (*_emp, qc_*, flux_ebullitive, …), so goFlux::flux.plot() and any other goFlux function run on it unchanged. flux_pdf() replaces flux2pdf() only because the latter fails with ggplot2 >= 3.5; it writes the same plots produced by flux.plot(). Every column of fluxes, with its origin:

column(s) origin produced by meaning

LM.flux, LM.C0, LM.Ct, LM.slope, LM.MAE, LM.RMSE, LM.AICc, LM.SE, LM.se.rel, LM.r2, LM.p.val goFlux (unchanged) goFlux::goFlux() linear model fit
HM.flux, HM.C0, HM.Ci, HM.slope, HM.MAE, HM.RMSE, HM.AICc, HM.SE, HM.se.rel, HM.r2, HM.k goFlux (unchanged) goFlux::goFlux() Hutchinson-Mosier fit
C0, Ct, MDF, prec, flux.term, nb.obs, k.max, k.mult, g.fact goFlux (unchanged) goFlux::goFlux() start/end concentration, goFlux’s MDF (datasheet prec), (V/A)(P/RT), n, kappa bounds, g-factor
best.flux, model, quality.check, HM.diagnose, LM.diagnose, HM.score, LM.score, *.lim, warn.nb.obs goFlux (unchanged) goFlux::best.flux() selected flux and why
<group>, <tissue> stemflux (added) auxfile via process_fluxes() grouping / tissue columns merged for the screens
sigma_emp stemflux (added) flag_detection() per-closure precision by the chosen estimator
MDF_emp, below_MDF_emp, MDF_emp_method stemflux (added) flag_detection() the reported MDF, its flag, and "<mdf> | <precision> | <conf>"
detected_emp, det_class_emp stemflux (added) flag_detection() emission / uptake / below detection by MDF_emp
sigma_<precision>, MDF_<mdf>_<precision>[_<conf>] stemflux (added, only with extra) flag_detection() comparison columns

events (add-on only): UniqueID, POSIX.time, Etime, dC (event size, gas units), threshold. settings: stemflux_version, goFlux_version, gastype, precision, mdf, conf, extra, sigma_global, qc (parameters of each screen), group, tissue, ebullition*, goFlux_args, best.flux_args, n_closures, date.

6. Plots by hand

CH4_plots <- flux.plot(CH4$fluxes, CH4$traces, "CH4dry_ppb", shoulder = 20,
                       plot.display = c("MDF", "prec", "nb.obs", "flux.term"))
CO2_plots <- flux.plot(CO2$fluxes, CO2$traces, "CO2dry_ppm", shoulder = 20)
flux_pdf(c(CO2_plots, CH4_plots), "plots/flux_results.pdf")   # ggplot2 >= 3.5 safe
