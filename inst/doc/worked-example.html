This vignette walks one real chamber closure through every step between the raw 1 Hz record and the number that would be reported in a table, printing every intermediate value. Nothing here is interactive, so the document can be rebuilt with rmarkdown::render().

The closure

example_closure() returns emission_stem_semirigid from the bundled set (?stemflux_examples): a tree-stem closure from the Yale-Myers Forest (Connecticut) monthly survey, spring 2021, semi-rigid sleeve chamber, ABB/LGR micro-portable UGGA logging at 1 Hz, shipped anonymized (synthetic calendar, no tree or plot identifiers) with the campaign’s clicked window and geometry:

auxfile column value meaning
Area 4254.121 cm2 stem surface enclosed
Vtot 7.082698 L chamber + tubing + analyzer cell
Tcham 26.02 C chamber air temperature
Pcham 101.325 kPa pressure

The rows carry the campaign’s water column, so goFlux applies its water-vapour correction to the flux term exactly as in the campaign processing.

Step 1: dead band (the clicked window)

The operator started the fitting window 91 s after the recorded closure time (chamber mixing, operator disturbance) and ended it after 765 s; that is the dead band as actually applied in the campaign. The rows with flag == 1 are what every fit below uses.

n_total <- nrow(d); n_used <- sum(d$flag == 1)
t_span  <- max(d$Etime[d$flag == 1]) - min(d$Etime[d$flag == 1])

Step 3: unit conversion

The gas columns are mole fractions: ppm = umol mol-1, ppb = nmol mol-1. A slope in ppb s-1 is therefore already in nmol mol-1 s-1; converting to mol mol-1 s-1 is a factor of 1e-9.

slope_ch4_molfrac <- slope_ch4 * 1e-9   # mol mol-1 s-1
slope_co2_molfrac <- slope_co2 * 1e-6
c(CH4 = slope_ch4_molfrac, CO2 = slope_co2_molfrac)
#>         CH4         CO2 
#> 3.36404e-10 8.24404e-07

Step 4: V/A and P/RT

Area_m2 <- 4254.121 / 1e4
Vtot_m3 <- 7.082698 / 1e3
T_K     <- 26.02 + 273.15
P_Pa    <- 101.325 * 1e3
R       <- 8.314
VA      <- Vtot_m3 / Area_m2          # m
PRT     <- P_Pa / (R * T_K)           # mol m-3 (molar density of air)
c(V_over_A_m = VA, P_over_RT_mol_m3 = PRT, product_mol_m2 = VA * PRT)
#>       V_over_A_m P_over_RT_mol_m3   product_mol_m2 
#>         0.016649        40.736954         0.678231

flux_term() is the same product written with goFlux’s unit conventions (litres, kPa, cm2, Celsius). goFlux also multiplies by (1 - H2O_mol), the mean water-vapour mole fraction of the window, to express the flux per mole of dry air; that is why its flux.term is slightly smaller than the dry product:

h2o <- mean(w$H2O_ppm) / 1e6                          # mol mol-1
ft0 <- flux_term(V_L = 7.082698, P_kPa = 101.325, A_cm2 = 4254.121, T_C = 26.02)
ft  <- flux_term(V_L = 7.082698, P_kPa = 101.325, A_cm2 = 4254.121, T_C = 26.02, H2O_mol = h2o)
c(flux_term_dry = ft0, H2O_mol = h2o, flux_term_with_H2O = ft, goFlux_flux.term = best_ch4$flux.term)
#>      flux_term_dry            H2O_mol flux_term_with_H2O   goFlux_flux.term 
#>         0.67823069         0.00951215         0.67177926         0.67186715

Step 5: flux

flux_ch4_mol   <- slope_ch4_molfrac * VA * PRT * (1 - h2o)        # mol m-2 s-1, dry-air basis
flux_ch4_nmol  <- flux_ch4_mol * 1e9                              # nmol m-2 s-1
flux_co2_umol  <- slope_co2_molfrac * VA * PRT * (1 - h2o) * 1e6  # umol m-2 s-1
c(CH4_flux_nmol_m2_s = flux_ch4_nmol, CO2_flux_umol_m2_s = flux_co2_umol)
#> CH4_flux_nmol_m2_s CO2_flux_umol_m2_s 
#>           0.225989           0.553818
# the shortcut used by goFlux: slope in ppb/s times flux.term gives nmol m-2 s-1 directly
c(shortcut = slope_ch4 * ft, goFlux_LM = best_ch4$LM.flux, goFlux_HM = best_ch4$HM.flux,
  goFlux_best = best_ch4$best.flux)
#>    shortcut   goFlux_LM   goFlux_HM goFlux_best 
#>    0.225989    0.226019    0.253722    0.253722

Step 6: per-measurement precision

Instrument noise is estimated from the measurement itself, not the datasheet. First differences remove the (linear) flux signal; white noise survives with variance 2 sigma^2, so sigma = SD(diff(x)) / sqrt(2).

sigma_ch4 <- precision_allan(w$CH4dry_ppb)
sigma_co2 <- precision_allan(w$CO2dry_ppm)
c(sigma_CH4_ppb = sigma_ch4, sigma_CO2_ppm = sigma_co2,
  datasheet_CH4_ppb = 0.9, datasheet_CO2_ppm = 0.35,
  robust_MAD_CH4_ppb = precision_mad(w$CH4dry_ppb))
#>      sigma_CH4_ppb      sigma_CO2_ppm  datasheet_CH4_ppb  datasheet_CO2_ppm robust_MAD_CH4_ppb 
#>           2.278275           0.828316           0.900000           0.350000           2.243483

This analyzer was about 2.5 times noisier in CH4 than its datasheet claims, which is why datasheet precision should not be used for detection limits.

Step 7: minimum detectable flux by each method, by hand

t_used <- max(w$Etime) + 1     # goFlux's t; = nb.obs at 1 Hz
mdf <- mdf_multi(flux.term = ft, t = t_used,
                 prec = 0.9,               # manufacturer, for the goFlux method
                 sigma = sigma_ch4,        # this closure (Christiansen, 2-sigma)
                 sigma.global = sigma_ch4) # a campaign median would go here (Wassmann)
t(round(mdf, 6))
#>                [,1]
#> MDF_goflux 0.000789
#> MDF_wass90 0.003286
#> MDF_wass95 0.003916
#> MDF_wass99 0.005147
#> MDF_chr90  0.009871
#> MDF_chr95  0.011767
#> MDF_chr99  0.015478
#> MDF_2sigma 0.003996
# by hand, Table 2.5 criterion: (2 sigma / t) (V/A) (P/RT)
c(MDF_2sigma_by_hand = (2 * sigma_ch4 * 1e-9 / t_used) * VA * PRT * (1 - h2o) * 1e9)
#> MDF_2sigma_by_hand 
#>         0.00399608

All MDFs are in nmol m-2 s-1. The regression standard error of the slope (LM.SE = 4.09^{-4} nmol m-2 s-1) is far smaller than any of them, which is the expected behaviour of these single-sample criteria.

Step 8: precision, MDF and detection flag with flag_detection()

flag_detection() does steps 6-7 for every row of a best.flux() table with one precision estimator and one MDF method and appends exactly six columns: sigma_emp, MDF_emp, below_MDF_emp, MDF_emp_method, detected_emp, det_class_emp. The default is the method of the companion data-processing manuscript: sigma = MAD(diff x)/sqrt(2) over the entire 1 Hz record of the field period (here: this closure’s whole trace, dead band included), and MDF = z sigma / t flux.term. The stated confidence is 95% two-sided, z = qnorm(0.975) = 1.96, i.e. the 2-sigma criterion (the companion manuscript itself used z = qnorm(0.95) = 1.645, its “90% confidence”). goFlux’s own columns (MDF, prec, best.flux, …) are left exactly as best.flux() produced them. Nothing is deleted; rows are flagged.

rep_ch4 <- flag_detection(best_ch4, traces = d, gastype = "CH4dry_ppb",
                          precision = "mad", mdf = "wassmann", conf = 0.95)   # the defaults, spelled out
setdiff(names(rep_ch4), names(best_ch4))
#> [1] "sigma_emp"      "MDF_emp"        "below_MDF_emp"  "MDF_emp_method" "detected_emp"  
#> [6] "det_class_emp"
t(as.data.frame(rep_ch4[, c("MDF", "sigma_emp", "MDF_emp", "MDF_emp_method", "below_MDF_emp",
                            "detected_emp", "det_class_emp")]))

Choosing precision and MDF

The default is fixed by the companion data-processing manuscript; the others are there so a report can state which one it used and readers can convert. Each method by its actual formula and origin:

Precision estimators

estimator formula computed over origin / use
mad (default) MAD(diff x) x 1.4826 / sqrt(2) the entire 1 Hz record of a field period (group) companion manuscript (mdf_FINAL_precision_and_detection.R): instrument-dominated at 1 s, a constant flux cancels, robust to moves and breaths
allan SD(diff x)/sqrt(2) flagged rows of each closure Allan deviation at tau = 1 s; per-closure noise
rolling median residual SD of the quietest 5 percent of 30-sample windows flagged rows of each closure comparison only; biased low on white noise
datasheet the prec value given to goFlux::import.*() – manufacturer 1-s specification (2.5x too optimistic here)
custom user-supplied sigma bench test Box 2 of the guidelines paper (sealed / standard-gas run)
per-closure sigma (qc_screens(noisy = ...)) MAD(diff x)/sqrt(2) on the closure’s flagged rows each closure diagnostic, not the MDF basis: fires qc_noisy when a closure is > k x noisier than its campaign sigma (disturbed closure?)

MDF methods (all = dC_min / t x flux.term)

method dC_min origin
wassmann (default) z x sigma_global, z = qnorm(1 - (1 - conf)/2); conf = 0.95 gives z = qnorm(0.975) = 1.96, so the default is the 2-sigma criterion Wassmann et al. (2018), PLoS ONE 13, e0191352; with the record-wide MAD sigma this is the companion manuscript’s MDF form (that manuscript used conf = 0.90, z = 1.645)
goflux p, the prec given at import goFlux’s built-in MDF(); goFlux’s documentation cites Christiansen et al. (2015) for it
christiansen sigma_i x 3 x t_crit(df = nb.obs - 2), two-sided as implemented in the author’s processing scripts under that name; the factor 3 is those scripts’ safety factor and is not attributed here to Christiansen et al. (2015) or Nickerson (2016), whose text was not checked
two_sigma 2 sigma_i the illustration of Table 2.5 of the guidelines paper

Which to use for what. Campaign means, budgets and upscaling: keep every flux and report the fraction below MDF_emp; removing values biases means. “Is this one flux non-zero?”: the per-closure variants (christiansen, two_sigma with allan) use the closure’s own noise. Cross-study comparison: extra = "all" and report the table.

Where each is set in the pipeline. The prec argument given to goFlux::import.*() (or the *_prec columns) only feeds goFlux’s own MDF column and the MDF criterion inside best.flux(). stemflux’s estimators are applied after best.flux() by flag_detection(), which reads the flagged traces and appends sigma_emp, MDF_emp, below_MDF_emp, MDF_emp_method (and the extra comparison columns if asked). goFlux’s columns are never modified. Nothing is deleted at any step: det_class_emp says "below detection", and the row stays.

Step 9: quality screens

Physical checks, each an independent flag (TRUE = fired), never a deletion. Is the CO2 tracer positive (the chamber was sealed and respiration accumulated)? Did the chamber start near ambient? Is the trace convex? Is the window long enough? With one measurement the C0 screen compares the closure to itself, so it passes trivially; in a campaign the median is taken over all closures.

rep_ch4 <- qc_screens(rep_ch4, traces = d, gastype = "CH4dry_ppb", co2 = best_co2,
                      screens = list(c0 = list(k = 1.5), co2_tracer = list(min_slope = 0),
                                     convex = TRUE, min_window = list(secs = 120), noisy = list(k = 1.5)),
                      verbose = FALSE)
t(as.data.frame(rep_ch4[, c("qc_c0", "qc_c0_ratio", "qc_co2_tracer", "qc_co2_slope", "qc_convex",
