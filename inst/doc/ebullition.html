Most chamber users (unsaturated surfaces) never meet ebullition and never need this vignette: the core path of fluxqc (goFlux -> best.flux -> flag_detection -> qc_screens, wrapped by process_fluxes()) does not call any of the code below. Over water, saturated peat or flooded vegetation, bubbles add abrupt step-ups to the smooth diffusive rise, and one linear or Hutchinson-Mosier fit through both components gives a number that is neither.

Since goFlux 0.3.0 this is goFlux’s job. Camille Minaudo added goAquaFlux() (with the internal find.bubbles() and flux.plot.aqua()): bubbling events are detected per closure from the rolling dispersion of the concentration series with an adaptive median + k x MAD threshold, each event’s step magnitude is estimated by a local step regression that separates the step from the diffusive trend and from the transient peak and re-equilibration that follow a bubble (goFlux 0.4.0), the diffusive flux is fitted with goFlux’s own model selection on the bubble-free part of the trace, and the ebullitive flux comes from the summed step magnitudes. fluxqc therefore no longer implements its own detector: the add-on is a thin adapter, detect_ebullition(), that forwards a click.peak2-style table to goAquaFlux() and appends the result to the flux table when process_fluxes(ebullition = "flag" | "split") is used. Despite its name, goAquaFlux() needs only Vtot, Area, Pcham, Tcham (and Etime, flag), so it applies to any bubbling surface.

A real closure with a bubble burst

ebullition_floating in fluxqc_examples() is a real 276 s floating-chamber closure on open water at a ghost-forest mangrove site of the NASA BlueFlux campaign (ABB/LGR GLA131). Geometry: Area 324.3 cm2, Vtot 4.318 L, Tcham 28.7 C, Pcham 101.325 kPa. CH4 rises diffusively from the first sample while CO2 rises cleanly from t = 0 (the chamber was already sealed); at 42-46 s the CH4 jumps by about 675 ppb over five consecutive samples (one burst; the campaign’s own single-sample threshold counted it as “5 jumps”), then resumes a steady rise. We put it next to the clean closure emission_stem_semirigid.

library(fluxqc)

goAquaFlux() finds the one event (high-dispersion window 23-63 s) and estimates a settled step of 1089 ppb. It reports an ebullitive flux, but flux_diffusive and flux_total are NA for this closure: goAquaFlux fits the diffusive term on the observations before the first bubble, and here the burst comes after only ~23 s, too few points. That is a property of the closure (an early burst), not of the method; for the clean closure the partition returns the whole-trace flux with zero ebullition. goFlux::flux.plot.aqua() draws goFlux’s own diagnostic plot for such results.

Through process_fluxes()

The add-on is an option of the pipeline, not a separate path. "flag" keeps the whole-trace best.flux and records the events; "split" additionally appends goFlux’s flux_diffusive, flux_ebullitive, flux_total (with SEs), n_obs_diffusive, first_bubble_time and ebullition_method = "goAquaFlux". goFlux’s own columns (best.flux, MDF, …) are never modified. Per-closure control comes from ebullition_ids or a logical ebullition column in the auxfile, so the closures known to bubble can be partitioned while the rest of the same call run the core path.

aux <- data.frame(UniqueID = c("emission_stem_semirigid", "ebullition_floating"), ebullition = c(FALSE, TRUE))
invisible(capture.output(       # goFlux's progress bar is captured
  res <- suppressWarnings(process_fluxes(both, aux = aux, gastype = "CH4dry_ppb",
                       qc = list(c0 = TRUE, convex = TRUE),
                       ebullition = "split"))))

Provenance and citation etiquette

fluxqc’s add-on contains no detection code of its own: all detection and partition is goFlux::goAquaFlux(), written by Camille Minaudo for goFlux 0.3.0-0.4.0. The earlier fluxqc implementations (a Hoffmann-style IQR fence filter, a fixed threshold and a running-variance method, none of which copied code from the Hoffmann Zenodo script or fluxCH4) were removed as duplicates. If you publish results obtained with the add-on, cite goFlux (Rheault, Christiansen & Larsen 2024, JOSS 9(96), 6393, doi:10.21105/joss.06393) and its aquatic partition (goFlux >= 0.3.0, C. Minaudo; see the goFlux changelog and package citation) alongside citation("fluxqc").

Limitations

Inherited from goAquaFlux(): the diffusive term needs enough bubble-free observations before the first event; analyzer artefacts (pressure transients, breaths on an inlet, valve switches) can look like bubbles; and the ebullitive rate assumes the bubbles caught in a 5-10 min closure represent the sampling period, which for episodic ebullition is rarely true. Review events against the traces (and flux.plot.aqua()) before reporting.
